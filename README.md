# «Я — профессионал» — PRO-навигатор, версия 3

Обновлено:
- жёлто-фиолетовая визуальная система по мотивам актуальной айдентики X сезона и предоставленного мерча;
- каталог с реальными фотографиями мерча;
- 8 наград: стикерпак, антистресс, блокнот, шоппер, бутылка, футболка, панамка, толстовка;
- сохранены тест, викторина, мини-хакатон и PRO-баллы.

Важно: официальный логотип не встроен в архив, потому что исходный RGB-файл логотипа не был загружен пользователем. В шапке стоит временный текстовый lockup. После загрузки официального PNG/SVG его можно заменить без переделки платформы.
